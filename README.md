Einkaufsanalyse
Dieses Java-Programm liest eine Einkaufsliste aus einer Textdatei ein und wertet die enthaltenen Artikel und Preise aus.
Funktionen
* Anzahl der Artikel zählen
* Gesamtpreis berechnen
* Durchschnittspreis berechnen
* Teuersten und günstigsten Artikel ermitteln
* Artikel unter 2 Euro zählen
* Gesamtpreis mit 10 % Rabatt berechnen
Verwendung
Die Datei einkaufsliste.txt enthält die Artikel und ihre Preise.
Das Programm wird über die Klasse Einkaufanalyse gestartet und liest die Datei mithilfe eines Scanners ein.
Technologien
* Java
* Scanner zum Einlesen der Datei
* Git zur Versionsverwaltung
